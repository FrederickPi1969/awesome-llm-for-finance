# Contributing

Please include the following fields for every paper submission:

- Title
- Year
- Paper URL
- Category
- Short note on why it belongs in this list
- Optional: code, dataset, model, benchmark, or project links

High-signal additions should be directly relevant to large language models,
foundation models, retrieval, reasoning, agents, or language-centric benchmarks
in finance. Generic ML/NLP papers should only be included when they are repeated
foundation references across finance LLM work.
