# Data Notes

This repository currently includes:

- The original 58-paper seed list.
- Enriched seed metadata from the Semantic Scholar Graph API.
- One citation/reference expansion pass over the resolved seed papers.
- A second citation/reference expansion pass over 40 high-relevance finance LLM
  candidates.
- A third citation/reference expansion pass over 35 recent, high-relevance
  promoted finance LLM candidates.
- A fourth citation/reference expansion pass over 30 strong round-3 candidates
  that were not yet curated.
- An expanded curated CSV plus top-200 first-, second-, third-, and fourth-round
  candidate CSVs.
- A longer relevance-filtered review list.
- Legacy/adjacent `*_110` expansion files covering finance plus geopolitical,
  geoeconomic, governance, forecasting, and strategic-simulation work. These are
  retained for auditability but are not used to build the main finance README.

The raw edge table is intentionally included so the ranking can be audited. The
candidate score is a curation aid, not an acceptance decision.

Abstracts and provider metadata are included for review convenience and remain
subject to their original rights and provider terms.
