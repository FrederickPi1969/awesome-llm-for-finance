# Data Notes

This repository currently includes:

- The original 58-paper seed list.
- A 110-paper combined seed list covering finance plus adjacent geopolitics,
  geoeconomics, governance, forecasting, and strategic-simulation work.
- Enriched seed metadata from the Semantic Scholar Graph API.
- One citation/reference expansion pass over the resolved seed papers.
- A preliminary top-200 candidate CSV and a longer relevance-filtered review list.
- A second 110-seed expansion pass with 9,454 raw citation/reference edges,
  3,815 longlist candidates, 405 preliminary curated additions, and 20 separated
  foundation/context papers.

The raw edge table is intentionally included so the ranking can be audited. The
candidate score is a curation aid, not an acceptance decision. Rows marked as
`low_confidence_top_result` in the enriched seed table should be checked before
being used as expansion seeds.

Abstracts and provider metadata are included for review convenience and remain
subject to their original rights and provider terms.
